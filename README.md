# Stockflow App 📦📊

Sistema modular de control de inventario y gestión de stock, diseñado para mantener un registro preciso,
rápido y estructurado de productos y movimientos comerciales.

## 🛠️ Tecnologías y Stack
* **JavaScript / Node.js**
* **Gestión de Base de Datos Local (`database.js`) **
* **Estructura escalable para aplicaciones de escritorio**

## 📂 Estructura del Proyecto
` ` `text
Stockflow-app/
├── src/            # Componentes y vistas del módulo de inventario
├── database.js     # Conexión y operaciones de base de datos
├── main.js         # Lógica principal de ejecución
├── package.json    # Configuración de dependencias y scripts
└── .gitignore      # Archivos ignorados por Git

⚙️ Instrucciones para Clonar y Probar Localmente
(Sección orientada a desarrolladores o reclutadores que deseen probar el proyecto)

Clonar el repositorio:
git clone https://github.com/SSalazar05/Stockflow-app.git

Instalar las dependencias de Node.js:
npm install

Iniciar la aplicación:
npm start
